# Instruções para o Agente de IA

Para este projeto, siga rigorosamente as seguintes recomendações em todas as interações:

1. **Não Abrir o Navegador**: Não utilize ferramentas de navegação ou subagentes de browser para visualizar ou testar a aplicação.
2. **Não Criar Plano**: Realize as alterações diretamente conforme solicitado, sem a necessidade de criar documentos de planejamento (`implementation_plan.md`) prévios, a menos que explicitamente solicitado.
3. **Testes pelo Usuário**: O agente não deve realizar validações funcionais no navegador. A responsabilidade de testar e validar as alterações visualmente ou funcionalmente é do usuário.

---
*Estas diretrizes visam agilizar o processo de desenvolvimento e respeitar a preferência de fluxo de trabalho do usuário.*
